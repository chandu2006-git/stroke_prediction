How it works

More than a prediction.

Every assessment moves through three stages: structured patient information, machine-learning analysis, and explainable results.

01 — Patient information

Demographic & health input

Age, gender, medical history, lifestyle factors and clinical measures are collected through a validated, accessible form.

02 — Machine learning

CatBoost classifier

Submitted information is analysed by a trained CatBoost model that returns a class prediction and a positive-class probability.

03 — Explainable results

SHAP & LIME explanations

Feature-level contributions reveal which inputs raised or lowered the predicted probability, for this specific patient.

Platform capabilities

Built for interpretability.

Each capability is designed to make the model's reasoning visible, not hidden.

01 Model

ML Prediction

CatBoost classification trained on tabular health data returns stroke / no-stroke with a calibrated probability.

02 Explainability

Explainable AI with SHAP

SHAP values quantify how each feature pushes the prediction up or down relative to the baseline.

03 Interpretability

A local surrogate model highlights the top contributing conditions for this individual assessment.

ML methodology

How the model was built.

A transparent overview of the approach and what is implemented versus still under evaluation.

  • Tabular healthcare dataset. Structured patient records with demographic, clinical and lifestyle features.
  • Data cleaning & feature preparation. Missing-value handling, categorical encoding and feature alignment with the training schema.
  • Class imbalance considerations. Stroke is relatively rare; the training pipeline accounts for imbalance.
  • CatBoost classification. A gradient-boosted decision-tree model handles categorical features natively.
  • SHAP global interpretability. Feature-level contribution values explain each prediction.
  • LIME local interpretability. A local linear surrogate approximates the model around an individual patient.
  • Probability calibration evaluation. Assessing whether predicted probabilities align with observed outcomes (under evaluation).

Implemented: CatBoost prediction + SHAP.
Under evaluation: probability calibration and full LIME integration in this build.
